# Animated 3D Portfolio - Mukul Batra

A modern, animated 3D portfolio website showcasing full-stack development skills with React.js, Three.js, and cutting-edge web technologies.

## 🚀 Features

- **Modern Design**: Glass morphism UI with futuristic aesthetics
- **3D Animations**: Interactive Three.js elements and Spline integrations
- **Responsive**: Optimized for all devices and screen sizes
- **Performance**: 60fps animations with adaptive quality settings
- **Accessibility**: WCAG 2.1 AA compliant with keyboard navigation
- **SEO Optimized**: Meta tags, structured data, and performance optimized

## 🛠️ Tech Stack

- **Frontend**: React.js 18+ with Vite
- **3D Graphics**: Three.js with React Three Fiber
- **Animations**: GSAP, Framer Motion, Spline
- **Styling**: Tailwind CSS with custom glass morphism effects
- **Performance**: Code splitting, lazy loading, WebGL optimization

## 📁 Project Structure

```
src/
├── components/
│   ├── layout/          # Navigation, footer, scroll progress
│   ├── sections/        # Hero, about, skills, projects, etc.
│   ├── ui/             # Reusable UI components
│   └── 3d/             # Three.js and 3D components
├── hooks/              # Custom React hooks
├── utils/              # Utility functions and animations
├── data/               # Data models and content
└── assets/             # Images, models, textures, resume
```

## 🚀 Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Start Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```

4. **Preview Production Build**
   ```bash
   npm run preview
   ```

## 📱 Sections

- **Hero**: Interactive profile with animated resume download
- **About**: Detailed professional introduction
- **Skills**: 3D skill bars with proficiency indicators
- **Education**: Timeline-style academic journey
- **Projects**: 3D animated project showcase
- **Achievements**: Trophy display with competition wins
- **Experience**: Professional timeline
- **Testimonials**: 3D rotating testimonial carousel
- **Contact**: Eye-catching contact information with particle effects

## 🎯 Performance Features

- Lazy loading for images and 3D models
- Code splitting for optimal bundle sizes
- WebGL fallbacks for unsupported devices
- Adaptive quality based on device performance
- Intersection Observer for scroll animations
